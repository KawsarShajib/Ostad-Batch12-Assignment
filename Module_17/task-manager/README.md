# Task Manager with API Integration

Vanilla JavaScript (ES6+), HTML5, CSS3. No frameworks or libraries.

## How to run
Open `async-practice.html` for Task 1 (Asynchronous JavaScript Practice)
Open `todos.html` for Task 2 (Todo/Task Manager App)
Open `api-todos.html` for Task 3 and 4 (Task Manager with API Integration, internet must). 


## Structure
- `async-practice.html` + `js/async-practice.js` : Task 1 (async concepts)
- `todos.html` + `js/todo.js` : Task 2 (Todo app)
- `api-todos.html` + `js/api-todos.js` : Tasks 3 & 4 (API fetch, filters, rendering)
- `css/style.css` : styling
