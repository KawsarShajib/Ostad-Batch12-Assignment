# Personal Expense Tracker

A beginner-friendly web application to track daily income and expenses.

## Features

- Add income and expense transactions
- View total income, total expenses, and current balance
- View transaction history
- Delete transactions with confirmation
- Edit transactions
- Filter transactions by All, Income, or Expenses
- Search transactions by title
- View monthly expense summaries
- Save data using browser localStorage
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run

1. Download or copy all project files into one folder.
2. Open the folder in VS Code or any code editor.
3. Open `index.html` in a web browser.
4. Add transactions and manage your income and expenses.

No installation or server is required.

## How Data Is Saved

All transactions are saved in the browser using `localStorage`.
Your transactions will remain available after refreshing or closing the browser.
